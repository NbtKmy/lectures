

# Data sources for GIS projects

This is a collection of the source data for workshops & lectures.


#### 国土数値情報 > 医療機関データ
**Link**:  
https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P04-v3_0.html

**Contents**:  
全国の医療機関の内、医療法に基づく「病院」「（一般）診療所」「歯科診療所」の地点、名称、所在地、診療科目、開設者分類をGISデータとして整備したものである。
本データは休止中の施設および企業内の施設等を含む。ただし、巡回のみの医療機関は含まない。

**Year of the data creation**:  
令和2（2020）年度 (The latest data)

**Copyrights**:  
[PDL1.0](https://nlftp.mlit.go.jp/ksj/other/agreement.html#agree-01)

**Last sighted**:  
2026-11-05

## Other GIS Data

### Overturemaps / The Overture transportation theme

**Source**:  
https://overturemaps.org/

**Description**:  
The Overture transportation theme is such a model: a global, open dataset of traversable segments (roads, railways, ferries) and connectors (intersections) representing how people and objects travel, built from OpenStreetMap and enhanced with data from TomTom and other local and regional authoritative data sources.

**How to get the data**:  
See the Doc: https://docs.overturemaps.org/guides/transportation/

**Attribution & Licence**:  
https://docs.overturemaps.org/attribution/
