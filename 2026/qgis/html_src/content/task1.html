Task 1 · Foreign permanent residents in Aichi

Goal: build a colour-coded map of Aichi from a plain table of numbers, then change one setting and watch the story change. About 25 minutes, done together.

Menu names follow QGIS 3.44; other versions differ slightly.

What you need

  • aichi_admin_fields2025.geojson — municipality boundaries of Aichi (MLIT N03, 1 January 2025).
  • aichi_permanent_residents_202512.csv — one row per municipality (Nagoya: per ward): city_code, pr_all, pr_brazil, pr_korea.

pr_all counts foreigners with the status permanent resident (永住者). pr_brazil is the part of them with Brazilian nationality. Both files share a 5-digit municipality code: 23201 is 23 (Aichi) + 201 (Toyohashi). That code is the key that lets you join them.

1 · Base map

  1. Choose Layer ▸ Add Layer ▸ Add XYZ Layer…. The Data Source Manager opens on the XYZ tab.
  2. Click New.
  3. Name: GSI standard
  4. URL: https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png
  5. Min. Zoom level: 5. Click OK.
  6. Select GSI standard in the list, click Add, then Close.

2 · Municipality polygons

  1. Drag aichi_admin_fields2025.geojson into the QGIS window.
  2. Right-click the new layer ▸ Open Attribute Table.
  3. Find the column N03_007: it is the municipality code. There are more rows than municipalities, because islands and exclaves are separate polygons. One row, 23000, is the unassigned area (所属未定地).

3 · Join the numbers

  1. Drag aichi_permanent_residents_202512.csv into the QGIS window. It appears as a table without a map.
  2. Double-click the polygon layer to open its Properties, then choose Joins.
  3. Click the green +.
  4. Join layer: the CSV. Join field: city_code. Target field: N03_007.
  5. Tick Custom field name prefix and delete the text in the box, so the new fields keep short names. Click OK.
  6. Open the attribute table again: pr_all, pr_brazil and pr_korea are attached.

If every joined value is empty, the two key fields differ in type (number vs. text). Check both in the attribute table.

4 · Colour by number

  1. Open the layer Properties ▸ Symbology. At the top, change Single Symbol to Graduated.
  2. Value: pr_brazil. Pick a colour ramp. Classes: 5.
  3. Click Classify, then OK.

Surprise 1 — the classes decide the picture. With the default Equal Interval, almost every municipality lands in the lowest colour. Reopen Symbology and change Mode to Equal Count (Quantile), click Classify. Then try Natural Breaks (Jenks). Same data, three different maps. No mode is neutral, so say which one you used.

5 · From counts to rates

  1. Open the polygon layer's Field Calculator (Ctrl+I; ⌘+I on a Mac).
  2. Tick Create virtual field. Output field name: rate_brazil. Type: Decimal number (real).
  3. Expression: "pr_brazil" / "pr_all" * 100. Click OK.
  4. Back in Symbology, set Value to rate_brazil and click Classify.

Surprise 2 — counts mostly show where many people live. By count the top three are Toyohashi (豊橋市, 4,182), Toyota (豊田市, 3,563) and Nishio (西尾市, 2,491). By share of all permanent residents the lead goes to Hekinan (碧南市, 64%), Shinshiro (新城市, 62%) and Toyone (豊根村, 60%). Toyone is 6 of 10 people.

6 · Export (optional)

  1. Project ▸ New Print Layout. Add a Map, a Legend, a Scale bar and a Title.
  2. Layout ▸ Export as Image.

Before you export: legend labels should read like words, not pr_brazil. Keep the base map pale so the data colours stand out. Put the source and date in the caption.

Watch out

  • Small numbers make wild rates. Shitara (設楽町) has 7 permanent residents in all; 3 Brazilians already read as 42.86%. Always look at the counts behind a rate.
  • Missing is not zero. The unassigned area 23000 has no data. It stays empty after the join and must not be coloured as 0.
  • Know what the category means. Permanent resident is one residence status. Special permanent residents (特別永住者) are a separate group and are not included.
